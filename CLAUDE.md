# Instructions for Claude

Do not edit this file.  Only Charlie Bouman changes it.

## Docstrings and comments

- Write for a person who has not read the code.
- Write complete sentences.  Each sentence has a subject and a verb, and it states one fact.
- Do not join two sentences with a comma.  Use ", and" or write two sentences.
- Use plain, standard words.  Do not invent names for things.
- Say what a function does and when to use it.  Leave out how it works inside, unless the caller needs to know.
- Keep docstrings short.  Shorten them by leaving out facts, not by leaving out words.
- Do not rewrite existing docstrings or comments unless you are asked to.
